# Template Start — ESP32 CYD Mawin IoT

โปรเจกต์ตั้งต้น (template) สำหรับบอร์ด **ESP32-2432S028 (CYD)** จอ 2.8" 320×240 + จอสัมผัส XPT2046
ใช้ **VS Code + PlatformIO**, **LVGL 8.3** และ **TFT_eSPI** หน้าจอเป็น**ภาษาไทย** (ฟอนต์ Chakra Petch)

ใช้เป็นจุดเริ่มต้นของโปรเจกต์ใหม่: งานพื้นฐานทำไว้ให้แล้ว เหลือแค่เพิ่มแท็บของโปรเจกต์ตัวเอง

| มีให้แล้ว | รายละเอียด |
|---|---|
| แท็บ **WiFi** | สแกน / เลือกเครือข่าย / ใส่รหัสผ่านด้วย keyboard บนจอ / ล้างรายการ / ลืม WiFi |
| แท็บ **ระบบ** | ข้อมูลบอร์ด, เวลาทำงาน, heap, แสง LDR, สถานะ WiFi, ปุ่ม calibrate, คำสั่ง Serial |
| หน้า **calibrate จอสัมผัส** | 5 จุด + จุดตรวจสอบ ขึ้นเองตอนบูตครั้งแรก |
| ชั้น **HAL** (`src/hal.h`) | จอ + ไฟหลังจอ, จอสัมผัส, RGB LED, LDR, ลำโพง, WiFi, ค่าที่จำถาวร (NVS) |
| ค่าบอร์ดใช้ร่วมทุกโปรเจกต์ | calibrate, ค่าจอ, ความสว่าง, ความดัง และ WiFi ตั้งครั้งเดียว เปลี่ยนโปรเจกต์แล้วไม่หาย |

> **สถานะ:** build ผ่านทั้ง `cyd_ILI9341` และ `cyd_st7789` ไม่มี warning จากโค้ดของโปรเจกต์
> ใช้ RAM 29.8% (≈ 98 KB) และ Flash 33.5% (≈ 1.05 MB จาก 3 MB)
> **ส่วน WiFi และการย้ายค่าเดิมยังไม่ได้ทดสอบบนบอร์ดจริง** ดูหัวข้อ 12

## 1. สิ่งที่ต้องมี

| รายการ | หมายเหตุ |
|---|---|
| บอร์ด ESP32-2432S028 (CYD) | รุ่น micro-USB (จอ ILI9341) หรือรุ่น USB-C (จอ ST7789) |
| สาย USB ที่ส่งข้อมูลได้ | สายชาร์จอย่างเดียวจะไม่เห็นพอร์ต |
| VS Code + ส่วนขยาย **PlatformIO IDE** | TFT_eSPI 2.5.43 และ LVGL 8.3.11 ดาวน์โหลดให้เองตอน build ครั้งแรก |
| ไดรเวอร์ USB-Serial **CH340** | ถ้า Windows ไม่เห็น COM port |
| WiFi 2.4 GHz | ESP32 ไม่รองรับ 5 GHz |
| ปากกาปลายมน (stylus) หรือเล็บ | แม่นกว่านิ้วมากตอน calibrate |

## 2. เริ่มใช้งาน

1. เปิดโฟลเดอร์ที่มี `platformio.ini` ใน VS Code
2. เลือก env ให้ตรงกับชิปจอ (ตารางด้านล่าง) ค่าเริ่มต้นคือ `cyd_ILI9341`
3. เสียบบอร์ด แล้ว Build + Upload

```powershell
pio run -t upload --upload-port COM3
pio device monitor -b 115200 --port COM3
```

(เปลี่ยน `COM3` ตามเครื่อง บอร์ด ST7789 ใช้ `pio run -e cyd_st7789 -t upload`
ถ้าไม่มีคำสั่ง `pio` ให้ใช้ `python -m platformio` ถ้า upload ไม่ผ่าน ให้กดปุ่ม **BOOT** ค้างตอนขึ้น `Connecting...`)

4. บูตแล้วจะเห็น splash **ESP32 CYD Mawin IoT** ถ้ายังไม่เคย calibrate จะเข้าหน้า calibrate เอง (หัวข้อ 5)
5. ไปที่แท็บ **WiFi** เพื่อเชื่อมต่ออินเทอร์เน็ต (หัวข้อ 3)

| env | ชิปจอ | บอร์ดที่พบบ่อย |
|---|---|---|
| `cyd_ILI9341` *(ค่าเริ่มต้น)* | ILI9341 | CYD รุ่นเดิม พอร์ต micro-USB |
| `cyd_st7789` | ST7789 | CYD รุ่นพอร์ต USB-C / จอรหัส `TPM408-2.8` |

เลือก env ผิด ภาพมักถูกตัดหรือเลื่อนไปครึ่งจอ ต้องเปลี่ยน env แล้ว upload ใหม่

## 3. แท็บ WiFi

```
┌──────────────────────────────────────┐
│        WiFi        │       ระบบ       │  ← แตะชื่อแท็บเพื่อเปลี่ยน
├──────────────────────────────────────┤
│ สถานะ WiFi                            │
│  MyHome                              │
│ IP 192.168.1.45   สัญญาณ -58 dBm      │
│ [ลืม WiFi (กดค้าง)]                   │
│ เครือข่ายที่พบ                          │
│ [สแกน] [ล้างรายการ]                    │
│ พบ 4 เครือข่าย แตะเพื่อเชื่อมต่อ           │
│ [✓ MyHome              -58 dBm รหัส] │
│ [Office_2G             -71 dBm รหัส] │  ← เลื่อนลงดูต่อ
└──────────────────────────────────────┘
```
(ภาพ ASCII วาดประกอบ ไม่ใช่ภาพจริง)

| ทำอะไร | ผล |
|---|---|
| **สแกน** | ค้นหาเครือข่ายเบื้องหลังประมาณ 2–4 วินาที (จอไม่ค้าง) เรียงจากสัญญาณแรงไปอ่อน ชื่อซ้ำรวมเป็นอันเดียว แสดงไม่เกิน `WIFI_SCAN_MAX` รายการ |
| **ล้างรายการ** | ล้างผลสแกนบนจอ (ไม่ตัดการเชื่อมต่อ) |
| แตะเครือข่ายที่**มีรหัส** | ขึ้นหน้าใส่รหัสผ่านพร้อม keyboard ปุ่มรูปตา = แสดง/ซ่อนรหัส ปุ่ม ✓ = เชื่อมต่อ ปุ่ม ✕ = ยกเลิก |
| แตะเครือข่าย**เปิด** | เชื่อมต่อทันที |
| แตะเครือข่ายที่มี **✓** (บันทึกไว้แล้ว) | เชื่อมต่อใหม่ทันที ไม่ต้องใส่รหัสซ้ำ |
| **ลืม WiFi (กดค้าง)** | ตัดการเชื่อมต่อ + ลบชื่อ/รหัสที่บันทึกไว้ |

การทำงานเบื้องหลัง (`src/hal_wifi.cpp`):

- **บันทึกเมื่อเชื่อมต่อสำเร็จเท่านั้น** พิมพ์รหัสผิด WiFi ที่บันทึกไว้เดิมไม่หาย
- บูตแล้ว**เชื่อมต่อเอง** (`WIFI_AUTO_CONNECT`) ถ้าหลุดหรือเชื่อมไม่ติด จะลองใหม่ทุก `WIFI_RETRY_MS` (30 วินาที)
- ไม่ติดภายใน `WIFI_CONNECT_TIMEOUT_MS` (15 วินาที) = ไม่สำเร็จ
- กด**สแกนระหว่างกำลังเชื่อมต่อ** โปรแกรมจะหยุดการเชื่อมต่อก่อน เพราะชิปทำสองอย่างพร้อมกันไม่ได้ แล้วจะลองใหม่เองตามรอบ
- รหัสผ่านต้องยาว 8–63 ตัวอักษร (WPA/WPA2)
- ชื่อ/รหัส WiFi เก็บใน NVS ของบอร์ด**แบบไม่เข้ารหัส** (เป็นวิธีปกติของ ESP32) ก่อนส่งบอร์ดต่อให้คนอื่น ให้กด **ลืม WiFi**

## 4. แท็บระบบ และคำสั่ง Serial

แท็บระบบแสดงชื่อโปรแกรม, เวอร์ชัน, รุ่นชิป, ความเร็ว CPU, flash, ขนาดโปรแกรม, ชิปจอ, เวอร์ชัน LVGL, สาเหตุที่บอร์ดเริ่มทำงาน, เวลาทำงาน, heap ว่าง, ค่าดิบ LDR, ความสว่าง, ความดัง, สถานะ/IP ของ WiFi และค่าความแม่นยำของการ calibrate พร้อมปุ่ม **Calibrate (กดค้าง)**

คำสั่ง Serial (115200 baud) พิมพ์ตัวอักษรเดียวแล้วกด Enter:

| คำสั่ง | ทำอะไร |
|---|---|
| `h` | แสดงรายการคำสั่ง |
| `i` | สถานะ (เหมือนบรรทัด `[STATUS]` ที่พิมพ์ทุก `STATUS_PRINT_MS`) |
| `c` / `k` | เริ่ม calibrate / แสดงสมการ calibrate และค่าดิบล่าสุด |
| `d` / `r` | แสดงค่าจอ (รวม MADCTL) / รีเซ็ตค่าจอเป็นค่าเริ่มต้น |
| `t` | เปิด/ปิดการพิมพ์ `[TOUCH] down/up ...` ทุกครั้งที่แตะ |
| `l` / `s` | ทดสอบ LED แดง→เขียว→น้ำเงิน→ขาว→ดับ / เล่นไล่โน้ต |
| `w` / `x` | สถานะ WiFi / ลืม WiFi |

ข้อความ WiFi ใน Serial ขึ้นต้นด้วย `[WIFI]` เช่น `connecting to '...'`, `connected '...' ip=... rssi=... dBm`, `saved`, `connect '...' timeout`, `scan done: N network(s)`

**ปุ่ม BOOT ค้าง 1 วินาที** = รีเซ็ตค่าจอเป็นค่าเริ่มต้น (ทางออกเมื่อตั้งค่าจอผิดจนมองไม่เห็น)

## 5. Calibrate จอสัมผัส

1. ขึ้นเป้ากากบาทสีเขียวทีละจุด: **บนซ้าย → บนขวา → ล่างขวา → ล่างซ้าย → กลางจอ**
2. แตะ**กลางเป้า**แล้ว**กดค้าง**จนแถบด้านล่างเต็ม จะมีเสียงปี๊บและข้อความ "ดีมาก ยกนิ้วขึ้นได้" แล้วจึงยกนิ้ว
3. ครบ 5 จุดแล้วจะมี**จุดตรวจสอบ**อีก 1 จุด
4. ผ่านทุกขั้นจะขึ้น `Calibrate สำเร็จ` พร้อมตัวเลขความแม่นยำ

calibrate ใหม่ได้ที่แท็บ **ระบบ → Calibrate (กดค้าง)** หรือพิมพ์ `c` ใน Serial ถ้าเข้ามาแล้วไม่แตะนาน 20 วินาที จะยกเลิกและใช้ค่าเดิม

| ข้อความที่ขึ้น | วิธีแก้ |
|---|---|
| `ยกนิ้วเร็วไป กดค้างจนแถบเต็ม` | แตะใหม่ที่เป้าเดิม |
| `นิ้วยังไม่นิ่ง กดค้างไว้นิ่งๆ` | กดแรงสม่ำเสมอ หรือใช้ปากกา |
| `แตะผิดจุด ...` / `คลาดเคลื่อน ... px` | เริ่มใหม่จากจุดที่ 1 |
| `จุดตรวจสอบคลาดเคลื่อน ... px` | เริ่มใหม่ |

วิธีคำนวณ: สมการ **affine** `x = a·u + b·v + c`, `y = d·u + e·v + f` (รองรับแกนสลับ / กลับด้าน / เอียงเล็กน้อย) หาค่าด้วย **least squares** จาก 5 จุด แต่ละจุดทิ้งค่าช่วงแรก แล้วใช้**มัธยฐาน** และตรวจผลด้วยจุดที่ไม่ได้ใช้คำนวณ (`src/hal_touch.cpp`)

## 6. ค่าที่จำถาวร (NVS)

ค่าแยกเก็บเป็น 2 ส่วน (ตั้งชื่อใน `include/app_config.h`):

| ส่วน | ชื่อ | key ที่เก็บ | ใช้ผ่าน |
|---|---|---|---|
| ค่าของ**บอร์ด** | `BOARD_NVS_NAMESPACE` = `cyd_board` | `cal` (calibrate), `disp` (ค่าจอ), `bl` (ความสว่าง), `vol` (ความดัง), `wifi_ssid`, `wifi_pass` | `hal::prefs()` (ภายใน HAL) |
| ค่าของ**โปรเจกต์** | `NVS_NAMESPACE` = `Mainstart` | ค่าที่โปรเจกต์ของคุณเก็บเอง | `hal::appPrefs()` |

- **ทุกโปรเจกต์ที่สร้างจาก template นี้ใช้ค่าบอร์ดชุดเดียวกัน** upload โปรเจกต์อื่นแล้วไม่ต้อง calibrate หรือตั้ง WiFi ใหม่ **ห้ามเปลี่ยน `BOARD_NVS_NAMESPACE` ในโปรเจกต์ลูก**
- ตั้ง `NVS_NAMESPACE` ไม่ซ้ำกันในแต่ละโปรเจกต์ ค่าของแต่ละโปรเจกต์จะได้ไม่ปนกัน (ยาวไม่เกิน 15 ตัวอักษร)
- **ย้ายค่าเดิมให้อัตโนมัติ:** บอร์ดที่เคยใช้โปรแกรมรุ่นเก่า (Lab_Template_Start, namespace `labstart`) บูตครั้งแรกจะคัดลอก `cal` `disp` `bl` `vol` มาที่ `cyd_board` ให้ (ไม่ลบของเดิม) Serial จะขึ้น `[NVS] migrated ...`
- ค่าจอจำแยกตามชิป ถ้าเปลี่ยน env เป็นอีกชิป จะเริ่มจากค่าเริ่มต้นของชิปใหม่
- ล้างค่าทั้งหมดของบอร์ด: `pio run -t erase` แล้ว upload ใหม่ (ต้อง calibrate และตั้ง WiFi ใหม่)

## 7. สร้างโปรเจกต์ใหม่จาก template

1. **คัดลอกโฟลเดอร์** ทั้งโฟลเดอร์ไปเป็นชื่อโปรเจกต์ใหม่ (ไม่ต้องคัดลอก `.pio/`)
2. แก้ `include/app_config.h`:
   ```cpp
   inline constexpr char APP_NAME[] = "Weather Station";   // ชื่อบน splash และแท็บระบบ
   inline constexpr char FW_VERSION[] = "v0.1.0";
   inline constexpr char NVS_NAMESPACE[] = "weather";       // ไม่ซ้ำกับโปรเจกต์อื่น
   // BOARD_NVS_NAMESPACE ห้ามแก้
   ```
3. **เพิ่มแท็บ:** สร้าง `src/ui_home.cpp`
   ```cpp
   #include "hal.h"
   #include "ui.h"

   namespace {
   lv_obj_t *gInfo;

   void tick(lv_timer_t *)  // งานที่ทำซ้ำ ใช้ lv_timer แทน delay()
   {
       if (hal::wifiConnected()) lv_label_set_text_fmt(gInfo, "ออนไลน์ IP %s", hal::wifiIp().c_str());
       else lv_label_set_text(gInfo, "ยังไม่ได้เชื่อมต่อ WiFi");
   }

   void onBeep(lv_event_t *)
   {
       hal::soundPlay(hal::Melody::Success);
   }
   }  // namespace

   void ui_home_tab(lv_obj_t *tab)
   {
       lv_obj_t *card = ui_card(tab, "หน้าหลัก");
       gInfo = ui_label(card, "");
       ui_btn(card, LV_SYMBOL_BELL " ทดสอบเสียง", onBeep);
       lv_timer_create(tick, 1000, nullptr);
       tick(nullptr);
   }
   ```
4. ประกาศใน `src/ui.h` และเพิ่มในตาราง `tabs[]` ของ `src/ui_main.cpp`:
   ```cpp
   // ui.h
   void ui_home_tab(lv_obj_t *tab);

   // ui_main.cpp
   const TabDef tabs[] = {
       {"หน้าหลัก", ui_home_tab},
       {"WiFi", ui_wifi_tab},
       {"ระบบ", ui_system_tab},
   };
   ```
   จอกว้าง 320 px ใส่ได้ประมาณ 4–5 แท็บ ชื่อแท็บควรสั้น

5. **เก็บค่าของโปรเจกต์** ด้วย `hal::appPrefs()` (เป็น `Preferences` ของ Arduino):
   ```cpp
   int count = hal::appPrefs().getInt("count", 0);
   hal::appPrefs().putInt("count", count + 1);
   ```

### ฟังก์ชันช่วยสร้าง UI (`src/ui.h`)

| ฟังก์ชัน | ใช้ทำ |

| `ui_row(parent)` | แถวโปร่งใส เรียงลูกแนวนอน ขึ้นบรรทัดใหม่เมื่อเต็ม |

| `ui_switch_row(parent, text, on, cb)` | ข้อความ + สวิตช์ |

| `ui_no_scroll(obj)` | widget ที่ลากได้ (แถบเลื่อน, พื้นที่วาด) ไม่ให้หน้าเลื่อนตามนิ้ว |

### ฟังก์ชันฮาร์ดแวร์ (`src/hal.h`)

| กลุ่ม | ฟังก์ชันหลัก |
|---|---|
| WiFi | `wifiConnected()`, `wifiIp()`, `wifiRssi()`, `wifiState()`, `wifiScanStart()`, `wifiConnect(ssid, pass)`, `wifiForget()` |
| เสียง | `soundTone(hz, ms)`, `soundSweep(from, to, ms)`, `soundPlay(Melody::Startup/Success/Error/Scale/Song)`, `soundSetVolume(0-3)` |
| RGB LED | `ledSetRgb(r, g, b)` ค่า 0–255 |
| จอ | `setBacklight(percent)`, `displayApply(cfg)` (invert / bgr / flipH / flipV) |
| จอสัมผัส | `touch()` (พิกัดล่าสุด), `touchCal()` |
| อื่นๆ | `ldrRaw()` (0–4095 ยิ่งสว่างยิ่งต่ำ), `resetReasonText()`, `appPrefs()` |

เสียงเล่นใน task แยก และ WiFi ทำงานเบื้องหลัง เรียกได้จาก callback ของ LVGL โดยไม่ทำให้จอหน่วง

### ข้อควรระวัง

- **ห้ามใช้ `delay()` ยาวๆ** ใน callback ของ LVGL หรือใน `loop()` ให้ใช้ `lv_timer_create()` แทน
- งานที่ใช้อินเทอร์เน็ต (HTTP, MQTT) ให้เช็ค `hal::wifiConnected()` ก่อน และอย่าทำงานที่รอนานในเธรดของ LVGL (ถ้ารอนาน ให้แยกเป็น FreeRTOS task)
- ต่อเซนเซอร์ใช้ I2C ที่ **GPIO27 (SDA) / GPIO22 (SCL)** **ห้ามใช้ GPIO21** (ขาไฟหลังจอ จอจะกะพริบ)
- ขา ADC2 (GPIO0, 2, 4, 12–15, 25–27) **อ่าน analog ไม่ได้ขณะเปิด WiFi** ใช้ ADC1 (GPIO32–39) แทน (LDR บนบอร์ดอยู่ GPIO34 เป็น ADC1 จึงใช้ได้)
- pin ทั้งหมดของบอร์ดอยู่ใน `include/board_config.h`

### ตัวอย่างแท็บทดสอบเดิม (`examples/removed_tabs/`)

แท็บ จอภาพ / สัมผัส / ไฟRGB / เสียง ของรุ่นเดิมเก็บไว้เป็นตัวอย่าง อยู่นอก `src/` จึงไม่ถูก build
ถ้าต้องการใช้ ให้คัดลอกกลับเข้า `src/` ประกาศฟังก์ชันแท็บใน `ui.h` และเพิ่มใน `tabs[]`
(`ui_display.cpp` ต้องประกาศ `ui_display_pattern_start()` และ `ui_display_refresh()` เพิ่ม ส่วน `ui_touch.cpp` มี `ui_touch_refresh()` ซ้ำกับ `ui_system.cpp` ต้องแก้ก่อน **ยังไม่ได้ทดสอบ build ไฟล์เหล่านี้กับ template ปัจจุบัน**)

แท็บ **จอภาพ** มีประโยชน์กับบอร์ดใหม่ที่สีกลับ / แดงสลับน้ำเงิน / ภาพกลับด้าน: ใส่กลับชั่วคราว ปรับสวิตช์จนจอถูก แล้วเอาออก ค่าจะจำไว้ใน `cyd_board` ให้ทุกโปรเจกต์

## 8. ค่าที่ปรับได้ใน `include/app_config.h`

| ค่า | ค่าเริ่มต้น | ผลเมื่อปรับ |
|---|---|---|
| `APP_NAME` / `FW_VERSION` | `Template Start` / `v1.0.0` | ชื่อและเวอร์ชันบน splash, แท็บระบบ, Serial |
| `NVS_NAMESPACE` | `Mainstart` | ที่เก็บค่าของโปรเจกต์ (หัวข้อ 6) |
| `STATUS_PRINT_MS` | 5000 | พิมพ์ `[STATUS]` ทุกกี่ ms (0 = ปิด) |
| `WIFI_AUTO_CONNECT` | true | บูตแล้วเชื่อมต่อ WiFi ที่บันทึกไว้เอง |
| `WIFI_CONNECT_TIMEOUT_MS` | 15000 | รอเชื่อมต่อนานสุดกี่ ms |
| `WIFI_RETRY_MS` | 30000 | ลองเชื่อมต่อใหม่ทุกกี่ ms (0 = ไม่ลองใหม่) |
| `WIFI_SCAN_MAX` | 15 | จำนวนเครือข่ายสูงสุดในรายการ |
| `TOUCH_Z_MIN` | 400 | แรงกดขั้นต่ำที่นับเป็นการแตะ (เพิ่ม = ต้องกดแรงขึ้น) |
| `TOUCH_PRESS_SAMPLES` / `TOUCH_RELEASE_SAMPLES` | 2 / 3 | กันสัญญาณรบกวนตอนกดลง/ปล่อย |
| `TOUCH_SMOOTH_ALPHA` | 0.6 | ความนิ่งของพิกัดขณะลาก (น้อย = นิ่ง แต่ตามนิ้วช้า) |
| `CAL_MARGIN` | 28 | ระยะเป้า calibrate จากขอบจอ (px) |
| `CAL_MAX_FIT_ERROR_PX` / `CAL_MAX_VERIFY_PX` | 6 / 7 | เกณฑ์ยอมรับผล calibrate |
| `BL_DEFAULT_PERCENT` / `BL_MIN_PERCENT` | 80 / 10 | ความสว่างเริ่มต้น / ต่ำสุด |
| `VOLUME_DUTY` / `VOLUME_DEFAULT` | 0, 24, 96, 512 / 2 | duty ของแต่ละระดับความดัง / ระดับเริ่มต้น (MID) |
| `CLICK_SOUND` | true | เสียงติ๊กเมื่อแตะจอ |

## 9. ข้อความภาษาไทย

ฟอนต์ `font_th_16` (ปกติ, ฟอนต์หลัก) และ `font_th_24` (ตัวหนา) สร้างจาก **Chakra Petch** มี ASCII, อักษรไทยทั้งหมด, `°` และสัญลักษณ์ `LV_SYMBOL_*` ของ LVGL

- พิมพ์ภาษาไทยในโค้ดได้ตรงๆ เช่น `lv_label_set_text(l, "อุณหภูมิ 25.5°C");` (ไฟล์ต้องเป็น UTF-8)
- LVGL 8 วางวรรณยุกต์ซ้อนสระบนไม่ได้ (เช่น "ที่", "นี้") อาจทับกันเล็กน้อย
- ภาษาไทยไม่เว้นวรรคระหว่างคำ LVGL จึงตัดบรรทัดกลางคำ ข้อความยาวให้**เว้นวรรคเอง**ตรงที่ตัดได้
- ตัวอักษรที่ไม่อยู่ในฟอนต์ (เช่น `·` `→` emoji) จะไม่แสดง เพิ่มได้ที่ `tools/gen_lvgl_fonts.ps1` แล้วสร้างใหม่ (ต้องมี Node.js):

```powershell
powershell -ExecutionPolicy Bypass -File tools\gen_lvgl_fonts.ps1
```

## 10. โครงสร้างไฟล์

```

│  ├─ hal.h, hal.cpp         ชั้นฮาร์ดแวร์ (ไม่รู้จัก LVGL): NVS 2 ส่วน + ย้ายค่าเดิม, LDR

│  ├─ hal_touch.cpp          อ่าน XPT2046 + สมการ affine + least squares
│  ├─ hal_led.cpp            RGB LED (PWM, active-LOW)
│  ├─ hal_sound.cpp          ลำโพง (PWM, เล่นใน task แยก)
│  ├─ hal_wifi.cpp           WiFi STA: สแกน / เชื่อมต่อ / บันทึก / ลืม / ต่อใหม่อัตโนมัติ
│  ├─ ui.h, ui_main.cpp      ธีม + splash + tabview (ตาราง tabs[]) + ฟังก์ชันช่วยสร้าง widget
│  ├─ ui_wifi.cpp            แท็บ WiFi + หน้าใส่รหัสผ่าน
│  ├─ ui_system.cpp          แท็บระบบ
│  ├─ ui_calibrate.cpp       หน้า calibrate จอสัมผัส
│  └─ fonts/                 font_th_16.c, font_th_24.c (สร้างด้วยสคริปต์ ห้ามแก้มือ)
```

## 11. ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ภาพถูกตัด / เลื่อนครึ่งจอ / มีขยะขอบจอ | เลือก env ผิดชิป (หัวข้อ 2) |
| สีผิด / ภาพกลับด้าน | ใส่แท็บจอภาพจาก `examples/removed_tabs/` กลับชั่วคราว (หัวข้อ 7) หรือเรียก `hal::displayApply()` |
| ตั้งค่าจอผิดจนมองไม่เห็น | กด BOOT ค้าง 1 วินาที หรือ Serial `r` |
| มีจุดสุ่ม / เส้นขยะบนภาพ | ลด `SPI_FREQUENCY` ใน `platformio.ini` เป็น `40000000` |
| แตะแล้วไม่ตรง | calibrate ใหม่ (แท็บระบบ) ใช้ปากกาปลายมน |
| แตะไม่ติด / ต้องกดแรงมาก | ลด `TOUCH_Z_MIN` (ดูค่า `z` ด้วย Serial `t`) |
| สแกนไม่เจอ WiFi ที่ต้องการ | ESP32 ใช้ได้เฉพาะ 2.4 GHz / เครือข่ายซ่อนชื่อจะไม่แสดง / เข้าใกล้เราเตอร์แล้วสแกนใหม่ |
| เชื่อมต่อไม่สำเร็จ | ตรวจรหัสผ่าน (ปุ่มรูปตา) / ดู `[WIFI]` ใน Serial / เครือข่ายที่ต้อง login ผ่านหน้าเว็บ (captive portal) ใช้ไม่ได้ |
| รีสตาร์ทเองตอนเชื่อมต่อ WiFi, แท็บระบบขึ้น `BROWNOUT` | ไฟจาก USB ไม่พอตอนวิทยุส่งสัญญาณ เปลี่ยนสาย/พอร์ต USB หรือใช้ hub ที่มีไฟเลี้ยง |
| ไม่มีเสียง | เสียบลำโพงที่ขั้ว SPEAK และความดังไม่ใช่ OFF |
| LED สีไม่ตรง / ตั้ง 255 แล้วดับ | ตรวจ `LED_PIN_*` และ `LED_ACTIVE_LOW` ใน `board_config.h` |
| ภาษาไทยบางตัวไม่แสดง | ตัวอักษรนั้นไม่อยู่ในฟอนต์ (หัวข้อ 9) |
| upload ไม่ผ่าน | ปิด Serial Monitor / กด BOOT ค้างตอน `Connecting...` / ถอดสายแล้วเสียบใหม่ |

## 12. สถานะการทดสอบ

| ข้อ | สถานะ |
|---|---|
| build ผ่านทั้ง `cyd_ILI9341` และ `cyd_st7789` | **ยืนยันแล้ว** ไม่มี warning จากโค้ดของโปรเจกต์ |
| จอ, จอสัมผัส, calibrate บน ILI9341 และ ST7789 | **ยืนยันแล้ว** บนบอร์ดจริง (2026-10-16 และ 2026-10-27) ก่อนปรับเป็น template โค้ดส่วนนี้ไม่ได้เปลี่ยน |
| แท็บ WiFi: สแกน / ใส่รหัส / เชื่อมต่อ / บันทึก / ลืม / ต่อใหม่อัตโนมัติ | **ยังไม่ได้ทดสอบบนบอร์ดจริง** |
| keyboard บนจอ (ขนาดปุ่ม, ฟอนต์, ภาษาไทยในหน้าใส่รหัส) | **ยังไม่ได้ดูจอจริง** |
| ย้ายค่าบอร์ดจาก `labstart` ไป `cyd_board` | **ยังไม่ได้ทดสอบบนบอร์ดจริง** |
| ค่าบอร์ดคงอยู่เมื่อ upload โปรเจกต์อื่นที่ใช้ `cyd_board` | **ยังไม่ได้ทดสอบ** (ตามการออกแบบควรคงอยู่) |
| ภาพ ASCII และตัวอย่างข้อความ Serial ในไฟล์นี้ | วาดประกอบ / ตามรูปแบบในโค้ด ไม่ใช่ผลจริง |
